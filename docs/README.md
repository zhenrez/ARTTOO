# ARTTOO Documentation

This directory is deliberately split by **authority**, not by chronology.

## Read this first

For product or implementation decisions, start at [authority/AUTHORITY.md](authority/AUTHORITY.md). It defines which evidence wins when documents disagree.

## Current authority

All current product, architecture, technology, capability, traceability, bootstrap-company, and MVP-autopilot contracts live under [authority/](authority/).

Do **not** reconstruct the product from historical files when a current authority document answers the question.

## Historical evidence

Historical originals and superseded implementation audits live under [authority/source-history/](authority/source-history/). They are retained for provenance and dispute resolution; they are not current architecture authority.

## Working rule

- Runtime/repository evidence beats prose.
- Current authority beats historical material.
- `mvp-autopilot/STATE.md` is a continuation record, not a product specification.
- Temporary implementation notes and one-off audits should not accumulate beside current operating contracts.
